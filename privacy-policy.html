Privacy Policy

EVAR HUD for Slither — Last updated: March 23, 2026

Overview

EVAR HUD for Slither ("the Extension") is a browser extension that provides a real-time heads-up display and analytics dashboard for the Slither.io and Slither.com browser games. We are committed to protecting your privacy.

Data We Collect

The Extension collects the following game-related data only while you are playing on slither.io or slither.com:

  • Game score (current, max, and final)
  • Kill count
  • Game duration
  • In-game nickname (as entered by you in the game)
  • Game server hostname

This data is stored locally on your device using Chrome's chrome.storage.local API. It never leaves your device unless you explicitly choose to submit it to the global leaderboard.

Global Leaderboard (Optional)

The Extension includes an optional global leaderboard feature. If you choose to submit your score:

  • A randomly generated anonymous player ID is created and stored locally
  • Your best score, kill count, game duration, and optional display name are sent to our database
  • No personal information (email, real name, IP address, location, or browsing history) is collected or transmitted
  • You may choose any display name or leave it as the default "Anonymous Snake"

Leaderboard data is stored on Supabase (a third-party database service). Their privacy policy is available at supabase.com/privacy.

Data We Do NOT Collect

  • Personal information (name, email, phone, address)
  • Browsing history or activity outside of slither.io / slither.com
  • Cookies or tracking identifiers
  • IP addresses
  • Location data
  • Financial information
  • Data from any website other than slither.io and slither.com

Permissions Explained

  • storage — Used to save your game history and extension settings locally on your device.
  • scripting — Used to inject the HUD overlay and game data reader into the Slither game page.
  • Host permissions for slither.io / slither.com — Required to inject the in-game overlay and read game variables. The Extension only activates on these specific game pages.
  • Host permission for supabase.co — Required for the optional global leaderboard feature to submit and retrieve scores.

Data Storage and Security

All game history is stored locally using Chrome's built-in storage API. Leaderboard submissions use HTTPS encryption in transit. No authentication credentials or sensitive data are stored or transmitted.

Data Retention

  • Local data: Stored indefinitely until you uninstall the extension or clear Chrome extension data.
  • Leaderboard data: Retained on the server until manually removed. You can request deletion by contacting us.

Third-Party Services

The only third-party service used is Supabase for the optional global leaderboard. No analytics, advertising, or tracking services are used.

Children's Privacy

The Extension does not knowingly collect personal information from children under 13. Since no personal information is collected from any user, COPPA compliance is maintained.

Changes to This Policy

We may update this privacy policy from time to time. Changes will be reflected by updating the "Last updated" date above. Continued use of the Extension after changes constitutes acceptance of the revised policy.

Contact

For questions or concerns about this privacy policy, please open an issue on our GitHub repository.
