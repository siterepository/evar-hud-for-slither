# EVAR HUD for Slither - Chrome Web Store Submission Guide

## Extension Name
EVAR HUD for Slither

## Short Description (max 132 characters)
Real-time HUD overlay for Slither with score tracking, kill stats, growth graphs, analytics dashboard, and global leaderboard.

## Detailed Description (for Chrome Web Store listing)

EVAR HUD for Slither adds a beautiful real-time overlay and full analytics suite to your Slither gameplay.

Track your performance live while you play with the in-game HUD that shows your score, kills, and growth graph -- all without obstructing your view.

FEATURES:

In-Game HUD Overlay
- Live score, kill count, and game timer
- Real-time score-growth graph with spike detection
- Personal best notifications and milestone alerts (10K, 25K, 50K, 100K)
- Kill streak detection (3+ kills in 25 seconds)
- Customizable position (4 corners), background opacity, and HUD size
- 5 color themes (Neon Cyan, Viper Green, Sunset, Arctic, Stealth)

Full Analytics Dashboard
- Lifetime stats: total games, best score, total kills, average duration
- Per-game history table with detailed breakdowns
- Player Strength analysis with tips to improve
- Session-by-session performance trends

Global Leaderboard
- Compete with players worldwide
- Submit your best score, fastest milestone times (10K, 20K, 50K, 100K)
- Anonymous by default -- choose any display name
- Profanity filter for clean competition

Customizable Settings
- Toggle HUD elements on/off (kills, score, graph, timer, notifications)
- Choose from 5 built-in themes
- Adjust overlay size and transparency
- All settings sync instantly to the HUD

Privacy First
- All game data stored locally on your device
- Global leaderboard is 100% optional and opt-in
- No personal information collected -- ever
- No ads, no tracking, no analytics
- Open source: https://github.com/siterepository/evar-hud-for-slither

Works on slither.io and slither.com.

## Single Purpose Description
This extension provides real-time gameplay analytics for the Slither browser game through an in-game HUD overlay and performance dashboard.

## Permissions Justification (for Chrome reviewer)
- storage: Saves game history and user settings locally on the device
- scripting: Injects the HUD overlay into slither.io/slither.com game pages
- Host permissions (slither.io, slither.com): Required to read game state and display the overlay
- Host permission (supabase.co): Required for the optional global leaderboard API calls

## SCREENSHOTS NEEDED (you must capture these)

Chrome Web Store requires at least 1 screenshot (1280x800 or 640x400).
Recommended: 3-5 screenshots showing different features.

### Screenshot 1: In-Game HUD
- Open slither.com and start playing
- Let the HUD show score, kills, and graph activity
- Take a screenshot at 1280x800 showing the HUD in the bottom-left corner during gameplay
- Caption: "Real-time HUD overlay tracks score, kills, and growth while you play"

### Screenshot 2: Extension Popup
- Click the EVAR HUD extension icon in the toolbar
- Show the popup with theme selector, toggles, and sliders
- Take a screenshot at 1280x800
- Caption: "Customize themes, toggle HUD elements, and adjust settings"

### Screenshot 3: Analytics Dashboard
- Open the dashboard (click Open Dashboard in popup)
- Show the summary cards, player strengths, and history table
- Take a screenshot at 1280x800
- Caption: "Full analytics dashboard with lifetime stats and game history"

### Screenshot 4: Global Leaderboard
- Open the dashboard and switch to the Global Top tab
- Show the leaderboard table
- Take a screenshot at 1280x800
- Caption: "Compete on the global leaderboard with players worldwide"

### How to take screenshots:
1. Resize your Chrome window to 1280x800 (use a window resizer extension)
2. Press F12 > Device Toolbar > set to 1280x800
3. Or use Windows Snipping Tool and resize to 1280x800 after
