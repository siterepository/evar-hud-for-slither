# EVAR HUD for Slither - Chrome Web Store Listing Copy

## Extension Name
EVAR HUD for Slither

## Short Description
Live Slither overlay with score/kill tracking, growth graph, and local performance dashboard.

## Detailed Description
EVAR HUD for Slither is a gameplay analytics extension for Slither.

It adds a live in-game overlay that tracks your current score, kills, and score-growth spikes in real time while you play.

Each run is automatically tracked as its own session, so the graph resets per game and your local history remains clean.

### Core Features
- Real-time Slither score and kill tracking
- Per-game score-growth graph with automatic session reset
- Local historical analytics and performance trends
- Personal best tracking (best size, kills, duration, gain, milestone speed)

## Privacy Description (Suggested)
EVAR HUD for Slither stores gameplay history in local extension storage on the user's device.

## Single-Purpose Statement (Suggested)
This extension's single purpose is to track and visualize Slither gameplay performance through a live overlay and local analytics dashboard.
