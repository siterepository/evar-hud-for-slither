# EVAR HUD for Slither

## Overview

EVAR HUD for Slither adds a live in-game overlay for Slither and records each run into local performance dashboards.

It tracks:
- current score and kills while playing
- score-growth spikes over time (per game)
- automatic game/session reset detection
- local historical analytics (averages, personal bests, trend graphs)

## Dashboard

- **Dashboard** (`stats.html`): local history, trends, averages, and personal best metrics.

## Install (Developer Mode)

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select:
   - `C:\Users\evarwon\OneDrive\Desktop\SLITHER SCORE LOG`
